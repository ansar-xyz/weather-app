# Weather App

A simple weather search tool. Enter a city name and get the current temperature and conditions.

## What It Does

- Search for any city
- Display current temperature in Celsius
- Show weather conditions (sunny, cloudy, rainy, etc.)
- Handle errors if the city isn't found

## How It Works

This app uses the OpenWeatherMap API to fetch real-time weather data.

## How to Use

1. Open 'index.html' in your browser
2. Type a city name in the search box
3. Click the search button
4. See the current weather

## Files

- 'index.html' — The app
- 'style.css' — Design and layout
- 'script.js' — Makes it work
- 'assets/' — Images

That's it. No installation needed.
